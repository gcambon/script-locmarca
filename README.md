## Quick start

**First connection** (Monday, TP0):
1. [Connect to JupyterLab on Kabre](docs/connexion_jupyterhub.md)
2. [Download the course material with git](docs/git_tp_course.md)
3. [Set up your bash environment](docs/bash_env.md)
4. [Select the Python environment](docs/python_env.md)

**Every following connection**: [connect to JupyterLab](docs/connexion_jupyterhub.md), then follow [Hands-on sessions](docs/handson_session.md) (update the material, work in your own copy of each notebook).
